# Erosbound Online — Alpha 0.1
Playable static MVP for GitHub Pages.

**Controls:** WASD/arrows — move, Space — attack, E — interact, R — respawn.

Includes a top-down map, PvE enemies, combat, HP, XP/levels, gold, an NPC with three positive interaction routes, quest/key progression, local saving, and ambient simulated players.

True realtime multiplayer will require a separate WebSocket backend; GitHub Pages hosts static clients only.
